# 🔍 Treasure hunt

Find the answers by exploreing this repo on GitHub. You don't need to clone anything.

**Tricks to try:** press `t` to search for a file, `/` to search the code, and `.` to open the repo in a full editor in your browser.

1. Which command counts the words in a sentence? *(hint: the README)*
2. Which file defines `is_palindrome`? *(hint: press `t`)*
3. What attendance percentage does the tool aim for unless you tell it otherwise? *(hint: search for `TARGET`)*
4. Which testing tool does this project use, and which file lists it?
5. What happens automatically every time someone opens a pull request? *(hint: look inside `.github/`)*
6. Two functions have **no tests at all**. Which ones? *(hint: read the `TODO`s in `tests/`)*
7. 🏆 Bonus: run `python -m textkit attendance 30 50`. The docs say the answer is 30. What do you get?
